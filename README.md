# Aplikasi Toko Sederhana

Aplikasi kasir toko sederhana dengan fitur:
- Input data barang (nama, harga)
- Pencatatan transaksi pembelian
- Perhitungan total belanja
- Output struk pembelian

## Struktur Project

- `src/Barang.php` - Class untuk data barang
- `src/Transaksi.php` - Class untuk transaksi pembelian
- `src/main.php` - Program utama
- `tests/UnitTest.php` - Unit test
- `tests/IntegrationTest.php` - Integration test

### Program Utama

php src/main.php
